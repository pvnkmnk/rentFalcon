## 2026-03-14 - Optimizing Deduplication and Parsing
**Learning:** `difflib.SequenceMatcher.ratio()` is computationally expensive for large lists of strings. It can be significantly optimized by a length-based short-circuit: the maximum possible ratio between two strings of length $L_1$ and $L_2$ is $(2 * \min(L_1, L_2)) / (L_1 + L_2)$. If this value is below the target threshold, the expensive comparison can be skipped entirely. Additionally, switching BeautifulSoup to the `lxml` parser provides a 20-30% speedup over `html.parser`, but must be handled with a fallback for environment compatibility.
**Action:** Always implement length-based short-circuits before expensive fuzzy matching. When using BeautifulSoup, use a try-except block to prefer `lxml` while maintaining `html.parser` as a fallback.
