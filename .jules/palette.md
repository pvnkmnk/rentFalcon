## 2025-05-14 - Loading State Feedback and Accessibility Standard
**Learning:** In applications with long-running async operations (like multi-source scraping), providing immediate, multi-layered feedback (both a global overlay and button-level state changes) significantly improves the perceived responsiveness. Accessibility is often overlooked in these states; using `role="status"` and `aria-live="polite"` ensures that screen reader users are informed of background progress without being interrupted.
**Action:** Always verify that async forms have corresponding UI state transitions in JS and that these transitions are communicated to assistive technologies via ARIA roles. Ensure that repetitive interaction elements (like listing links) have dynamic `aria-label` context to avoid "View Listing" redundancy.
